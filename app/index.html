ScanMend - Kane CLI Online Hackathon entry. Model: custom multi-head CNN (blur / contrast-loss / noise / skew), trained on synthetic degraded documents, runs in-browser via TensorFlow.js (Apache-2.0). OCR: Tesseract.js (Apache-2.0). PDF: jsPDF (MIT). All libraries loaded from CDN; first load needs a connection. Known limits: noise estimation is weak on downscaled thumbnails (see README eval), OCR quality depends on the source image, exported PDF is searchable but not accessibility-tagged.
